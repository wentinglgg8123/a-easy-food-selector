# 食刻決定｜清大今天吃什麼

從 Excel 餐廳清單隨機推薦一餐的繁體中文網站，支援清華大學校內及周邊 2 公里範圍的用餐選擇。使用 React 19、Vite 8 與 TypeScript，Excel 讀寫採用 `read-excel-file` 與 `write-excel-file`。

**目前隨附的是 8 間虛構示範餐廳，不是清大真實或完整的餐廳名單。** 請匯入自己確認過的資料，才適合用於實際推薦。

## 本機開發

需要 Node.js 22.12 以上，建議使用 Node.js 24。

```bash
npm ci
npm run dev
```

開啟終端機顯示的網址。網站完全在瀏覽器中執行，不需要後端服務、帳號或 API 金鑰。

```bash
npm run typecheck  # TypeScript 檢查
npm test           # 自動測試
npm run build      # 檢查型別並產生 dist/
npm run preview    # 預覽建置結果
```

瀏覽器端測試涵蓋桌面與手機版的抽選、篩選、Excel 匯入與範本下載，以及無障礙和版面檢查。首次執行前需安裝測試用 Chromium：

```bash
npm exec playwright install chromium
npm run test:e2e
```

測試會自動啟動開發伺服器；目前雲端環境也可使用已安裝的 Chromium：

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

## 使用方式

1. 先用示範資料體驗，或下載 Excel 範本並替換成真實餐廳資料。
2. 匯入 `.xlsx` 檔案，查看匯入結果與資料警告。
3. 依區域、類型、最高均消或關鍵字篩選，再隨機選一家。
4. 符合條件的餐廳有兩間以上時，下一次抽選會避開上一間。

匯入的名單會保存在目前瀏覽器、目前網站網址的 `localStorage`，重新整理後仍可使用。清除匯入資料會恢復示範名單；不同裝置、瀏覽器或網站網址之間不會同步。

## Excel 格式

僅接受不超過 5 MB 的 `.xlsx` 檔案。程式只讀取第一個工作表，第一列須為欄位名稱，最多支援 5,000 筆資料列。

| 欄位         | 必填 | 說明                                   |
| ------------ | ---- | -------------------------------------- |
| 餐廳名稱     | 是   | 餐廳或攤位的名稱                       |
| 區域         | 是   | `清大校內` 或 `校園周邊`               |
| 類型         | 否   | 例如便當、麵食、早餐、素食             |
| 均消         | 否   | 每人平均消費，填寫新臺幣數字           |
| 距離（公里） | 否   | 與統一基準點的距離，填寫公里數字       |
| 地址         | 否   | 用於顯示及開啟 Google Maps 搜尋        |
| 備註         | 否   | 可記錄營業資訊、資料來源及最後查證日期 |

範本也包含 8 間虛構餐廳，請先刪除或替換範例。匯入時會略過無效資料列、移除重複資料並顯示警告；`校園周邊` 中距離超過 2 公里的餐廳會被排除。缺少距離的餐廳會標示為尚未確認。

距離由 Excel 提供，網站不會定位、計算路線或自動查證地址。整理資料時請選定一致的基準點，例如清華大學校本部校門，並自行確認餐廳名稱、地址、均消及距離。網站目前未蒐集清大校內及周邊所有店家，不能保證名單完整或資訊即時。

## 資料與部署

Excel 在瀏覽器本機解析，檔案內容不會傳送至伺服器。點選地圖連結時，瀏覽器才會開啟外部 Google Maps，並以餐廳地址進行搜尋。

建置後的 `dist/` 可部署到支援靜態網站的服務。本專案不需要執行中的應用程式伺服器；網站的公開部署需另行設定。
